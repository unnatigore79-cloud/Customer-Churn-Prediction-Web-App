# 📊 Customer Churn Prediction Web App

An end-to-end Data Science & Machine Learning project that predicts customer churn risk based on service usage, subscription tenure, monthly charges, and technical support access.

---

## 📌 Project Overview
Customer churn directly impacts business revenue and customer retention. This interactive web application uses a trained **Random Forest Classifier** to assess whether a customer is at **High Risk** or **Low Risk** of churning.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Data Analysis & Viz:** Pandas, NumPy, Seaborn, Matplotlib
- **Machine Learning:** Scikit-Learn
- **Web App Framework:** Gradio
- **Environment:** Google Colab / VS Code
